🛒 Sajjan Shopping Cart

«A simple, interactive Java-based shopping cart application built to demonstrate Core Java, Object-Oriented Programming, and real-world application logic.»

Welcome to Sajjan Shopping Cart! 🚀

This project is a command-line shopping application where users can browse products, place orders, modify their orders, view order details, and cancel orders.

The main goal of this project is to transform Java fundamentals into a practical application while improving problem-solving and programming skills.

---

✨ Why This Project?

Learning Java concepts is one thing.
Using those concepts to build a working application is another. 💡

Sajjan Shopping Cart brings together multiple Core Java concepts into one practical project.

It demonstrates how:

Java Concepts → Application Logic → User Interaction → Complete Project

🎯 Key Features

Feature| Description
👤 User Flow| Simple user interaction and selection
🛍️ Product Selection| Browse and select available products

💰 Price Calculation| Automatically calculates the order total
🧾 Order ID| Generates unique order details
✏️ Modify Order| Modify the order before confirmation
📦 View Orders| View placed orders
❌ Cancel Order| Cancel confirmed orders
📊 Order Status| Track the current order status

🚀 How to Run

1️⃣ Clone the Repository
git clone :https://github.com/akshatassajjan/shopping-cart-.git


2️⃣ Open the Project

Open the project in:

- VS Code
- IntelliJ IDEA
- Eclipse
- Any Java-supported IDE

3️⃣ Compile the Program

javac *.java

4️⃣ Run the Application

java Main

«Note: If your main class has a different name, replace "Main" with your class name.»
